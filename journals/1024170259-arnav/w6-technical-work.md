# Week 6 : Skin-Type Dataset Preparation

## Dataset Collection and Cleanup

I worked on preparing image data for the skin-type classifier, covering oily, dry, and normal skin. The dry-skin examples were collected and organized, while the oily and normal images were reviewed and cleaned. I removed duplicate images, corrected class labels where needed, and kept a record of image sources.

## Dataset Organization

I organized the images by skin-type class so they could be used by the planned MobileNetV2 training workflow. This preparation established the dataset structure for the later count and duplicate checks.
